# Статистика

Вкладка для просмотра статистики по нарядам, отчётов и сравнения.

## Общая статистика

Сверху — сводка по всей базе: сколько участков, нарядов, проб, найдено, отложено, с ошибками.

## Статистика по наряду

Выберите участок и наряд — увидите:

- Общее количество проб.
- Сколько отмечено.
- Сколько холостых, ВК, отложенных.
- Сколько ещё не отмечено.

Можно переключаться между нарядами — цифры обновляются мгновенно.

## Отчёты

### Excel

Кнопка **Экспорт Excel** — сформировать отчёт по выбранному наряду в формате `.xlsx`. Удобно для распечатки или отправки.

Поддерживаются:

- Одиночный наряд.
- Несколько нарядов одновременно (мультиотчёт).
- Цветовая легенда статусов.
- Гиперссылки на фото.

### HTML

Кнопка **Экспорт HTML** — тот же отчёт, но в формате веб-страницы. Открывается в любом браузере, без Excel.

## Сравнение нарядов

Кнопка **Сравнить** — сравнить два наряда между собой по количеству проб, отметок, холостых.

## Графики

Диаграмма найденных и отложенных по нарядам — для быстрой оценки прогресса.

## Поиск

Строка поиска сверху — найти конкретный наряд по номеру или участок по названию.

## Что можно увидеть с одного взгляда

- Какие наряды не закрыты (мало отмечено).
- Где много ошибок импорта.
