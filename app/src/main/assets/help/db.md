# База данных

Вкладка для управления базой: бэкапы, восстановление, откат, очистка, слияние, сравнение и диагностика.

## Инфо-панель

Сверху — сводка по базе: путь к файлу, размер, дата последнего изменения, число участков, нарядов, скважин, проб, фото и заметок.

Обновляется автоматически при заходе на вкладку.

## Экспорт бэкапа

Кнопка **Экспорт** — сохранить базу в файл `.gsmbackup`. Это zip-архив со всей базой и папкой фото.

Файл можно сохранить в Загрузки или поделиться через любое приложение.

## Импорт бэкапа

Кнопка **Импорт** — восстановить базу из файла `.gsmbackup`. Показывается список файлов из `Загрузки/GeoSampleManager/exports/`. Можно также выбрать файл через системный проводник.

Перед заменой приложение автоматически создаёт резервную копию текущего состояния.

## Откат

Кнопка **Откат** — вернуться к одному из авто-бэкапов. Авто-бэкапы создаются автоматически перед каждой операцией:

- `pre_restore` — перед импортом.
- `pre_rollback` — перед откатом.
- `pre_clean` — перед очисткой.
- `pre_diagnostics` — перед диагностикой.

Хранятся последние 5 для каждой операции — в приватной папке и в Загрузках.

## Очистка

Кнопка **Очистка** — полностью стереть базу: все участки, наряды, пробы, фото, заметки.

Требуется двойное подтверждение.

## Управление бэкапами

Кнопка **Менеджер** — сводка по всем бэкапам с возможностью:

- Удалить один.
- Удалить старые (ручная ротация).
- Удалить все авто-бэкапы (экспорты не трогаются).

## Слияние двух баз

Кнопка **Слияние** — слить текущую базу с другой базой из `.gsmbackup`. Приложение покажет предпросмотр: новые записи, идентичные, конфликты.

Конфликты разрешаются вручную: по каждому полю или массовой стратегией.

## Сравнение баз

Кнопка **Сравнить** — сравнить текущую базу с другой. Показывается 4 дерева:

- **Только у меня** — есть в текущей, нет в архиве.
- **Только в архиве** — есть в архиве, нет у меня.
- **Совпадает** — идентичные.
- **Различается** — отличаются в полях.

## Диагностика

Кнопка **Диагностика** — поиск проблем в базе:

- Наряды без участка.
- Пробы без наряда.
- Битые ссылки на фото.
- Несоответствие флага `has_photo`.

Перед исправлением — авто-бэкап.
