## Известные грабли (важно!)

- **`AS Commit` ломает репо.** Панель Commit в Android Studio при
  кликах по changelist'ам может показать фантомные «deleted» и
  удалить файлы из рабочего дерева. **Инцидент 29.09.2026:** пришлось
  делать `git revert` ошибочного коммита `6bc46b5`, восстанавливать
  6 файлов, коммитить добором.
  **Правило:** все git-операции — **только через терминал**.
- **Gradle test-worker'ы падают при многопоточной сборке.**
  `./gradlew testDebugUnitTest` запускает 24 воркера параллельно —
  на этой машине падают с `Could not find class GradleWorkerMain`.
  **Обход:** запускать тесты через **AS-runner** (Project panel →
  правый клик по папке `data/report` → `Run 'Tests in ...'`) или
  `./gradlew testDebugUnitTest --no-daemon --max-workers=1`.
- **Файл легко сохранить не в ту папку.** В AS бывает, что новый
  файл создаётся не там (например, в `.github/app/...`). Всегда
  проверяй вывод merge: если появился путь с префиксом `.github/app/` —
  это ошибка. Быстрая проверка: `git ls-files | findstr ИмяФайла`.
