## 1. Экран «Сверка и поиск»

### Общее
- Одна вкладка.
- Два **неявных** режима:
    - **Поиск** — наряд не выбран, ищем по всей БД.
    - **Сверка** — наряд выбран, работаем по нему с приоритетом.
- Переключателя режимов нет — всё автоматически.

### Селекторы сверху
- **Участок** (опционально). Список участков — из БД.
- **Наряд** (опционально). Список нарядов **зависит от участка**.
    - Если участок не выбран — все наряды.
    - Если выбран — только наряды этого участка.
- **Пустые наряды (без проб) не показываются.**
- **Кнопка-шестерёнка** рядом с нарядом — открывает настройки наряда.
    - Активна только когда наряд выбран.

### Поле поиска
- Принимает **номер скважины или пробы**, с префиксом или без.
- Префикс = участок. Если указан — сужаем поиск до участка.
- **Крестик** очищает поле, но **не** скрывает клавиатуру.
- **«Поиск» на клавиатуре** — скрывает клавиатуру.
- Поиск идёт **по всей БД** (не только по выбранному наряду), чтобы
  находить пробы из чужих нарядов.

### Логика поиска
1. **Пусто + ничего не выбрано** → подсказка «Введите номер скважины или пробы».
2. **Пусто + выбран участок без наряда** → подсказка
   «Выберите наряд или введите номер».
3. **Пусто + выбран наряд** → все пробы этого наряда.
4. **Запрос есть** → поиск по всей БД:
    - **точное совпадение с номером скважины** → все пробы этой скважины;
    - **совпадение с началом номера пробы** → такие пробы.
5. **Совпадение номера пробы с номером скважины** (или короче) —
   это **ошибка импорта**. Подсвечивается иконкой + фоном.

### Индикатор-фонарик
- Слева от поля поиска.
- **Горит** (жёлтый), если ответ единственный — то есть проба или
  скважина встречается только в одном наряде (с учётом выбранного участка).
- **Не горит** — совпадений несколько.
- Рядом с фонариком — **название наряда** (если горит) или «Несколько».

### Приоритеты результатов
- **Выбранный наряд** — сверху, обычный вид.
- **Тот же участок, другой наряд** — ниже, полоска + «Не из выбранного наряда».
- **Другой участок** — ещё ниже, красная полоска + «Другой участок».

## 2. Строка пробы

### Колонки (слева направо)
1. Чек-бокс «найдена».
2. **п/п** — порядковый номер в группе (1, 2, 3…).
3. **№ скважины / выработки** — заголовок динамический:
    - «Выработка», если в группе есть бороздовые (`channel`),
    - иначе «Скважина».
4. **№ пробы** + подпись «№ в скв.: N» (вычисляется из `sample_number` минус
   `well_number`).
5. **Интервал** (`от–до`) + подпись «интервал, м».
6. **Вес** — основной вес + вес ВК в скобках (если есть).
7. **Характеристика** — обрезается до 2 строк, кликабельна → диалог
   с полным текстом.
8. **Тип** — «Шнековая» / «Бороздовая» / «Холостая» / «Весовой контроль» /
   «Кобра» / «Дубликат».
9. **Иконки справа**: ВК, отложена, заметка, фото, ошибка.
10. **3 точки** → меню действий.

### Цвет фона строки — приоритет
1. **Найдена** → зелёный (перебивает всё).
2. **Ошибка** → красный.
3. **Отложена** → голубой (отличается от холостых и ВК).
4. **Холостая** → жёлтый.
5. **Весовой контроль** → фиолетовый.
6. **Не найдена** → без фона.

**Приоритет цвета:** найдена > ошибка > отложена > холостая > ВК > обычная.

**Все признаки помимо цвета показываются иконками справа** —
отложена, заметка, фото, ВК, ошибка.

## 3. Логика чек-бокса

При клике по чек-боксу:

| Ситуация | Что происходит |
|---|---|
| Уже найдена | Диалог действий: снять отметку / отложить / заметка / редактировать |
| Ошибка импорта | Диалог: продолжить / редактировать / отмена |
| Отложена | Диалог: отметить как найденную / заметка / отмена |
| ВК без веса | Диалог ввода веса ВК |
| Холостая | Зависит от настроек: авто-вес FIXED / AVERAGE / ручной ввод |
| Обычная | Просто отметить как найденную |

## 4. Вес, ВК, холостые

### Основной вес
- Поле `weight` в БД.
- Вводится вручную в таблице (тап по ячейке веса) или автоматически.
- Основной вес задаётся при импорте из Excel.

### Весовой контроль (ВК)
- Флаг `weight_control: Boolean`.
- Вес ВК — `control_weight: Double?`.
- ВК **не может быть холостой**.
- Постановка ВК на найденную пробу **сбрасывает `found` и `control_weight`** —
  рабочему надо заново взвесить.
- **При нажатии на ячейку веса ВК открывается диалог** — можно ввести
  или изменить вес.

### Холостая проба
- `status = "blank"`.
- **Не может быть ВК и не может быть отложенной.**
- Может иметь вес (задаётся вручную или автоматически).
- Если у холостой нет веса и при отметке — открывается диалог ввода.

### Настройки холостых
Хранятся **в памяти состояния** (в БД пока не сохраняются, см. `NEXT_STEPS.md`).

Три режима:
- **FIXED** — единый вес на наряд.
- **AVERAGE** — среднее соседних не-холостых проб.
- **MANUAL** — ручной ввод.

**При сохранении** FIXED/AVERAGE вес **проставляется СРАЗУ** всем холостым
без веса, но **`found` НЕ ставится** — рабочему надо отметить их вручную.
Показывается снекбар: «Вес проставлен N пробам — отметьте их вручную».

**Единый и средний вес не применяются к уже введённым весам.**
Если вес уже был — он не меняется.

**Кнопка «Сбросить вес холостых»** в диалоге настроек:
- сбрасывает вес у **всех** холостых наряда,
- снимает отметки `found`,
- с подтверждением.

## 5. Массовые действия

### «Выделить все» в группе
1. Собираем список проб, требующих решения:
    - ВК без веса — надо ввести вес,
    - отложенные — надо решить (отметить или оставить).
2. Если таких нет — сразу отмечаем всё, что можно.
3. Если есть — открывается **диалог решений**:
    - для каждой ВК без веса — поле ввода веса,
    - для каждой отложенной — чек-бокс «Отметить как найденную».
4. После «Применить» — отмечаем по решениям.

**Пропускаются при массовой отметке:**
- ошибки,
- холостые без веса при MANUAL,
- ВК без введённого веса.

### «Сбросить все» в группе
- С подтверждением.

## 6. Undo / Redo

- До **20** шагов.
- Кнопки «Отмена (N)» и «Вперёд (N)» в верхней панели.
- **Статус-бар** между кнопками описывает верхнее undo-действие:
  «Отметить: TST123401», «Вес: 2.5 кг (TST123402)», «Удалить: TST123403» и т.д.
- Любое **новое** действие **очищает стек redo**.
- **Удаление пробы** пишется в undo с полным восстановлением:
  строка возвращается на исходный индекс, все затронутые `sample_number` и
  `numberInWell` возвращаются из before-снимка.

## 7. Удаление пробы

Через **3 точки** → «Удалить».

Диалог:
- подтверждение,
- чек-бокс **«Пересчитать № проб в скважине»** (по умолчанию выключен).

**Если чек-бокс включён:**
- `sample_number` и `numberInWell` всех проб скважины в наряде
  пересчитываются подряд: 1, 2, 3…;
- длина суффикса сохраняется (2 знака, 3 знака — как в исходных данных).

**Если выключен:**
- только `numberInWell` пересчитывается,
- `sample_number` остаётся как был.

Вся операция — в одной транзакции.

## 8. Типы проб

| Код в БД | Название в UI | Примечание |
|---|---|---|
| `auger` | Шнековая | По умолчанию |

| `cobra` | Кобра | |

| Код в БД | Название в UI |
|---|---|
| `normal` | Обычная |
| `blank` | Холостая |

## 9. Настройки наряда

Диалог из шестерёнки. Две секции.

### Холостые пробы
- FIXED / AVERAGE / MANUAL (радио).
- Поле «Единый вес» (если FIXED).
- Пояснение: вес применяется только к холостым без веса, **не отмечает** их.
- Кнопка **«Сбросить вес холостых в наряде»** (красная, с подтверждением).

### Весовой контроль
- Поле «Каждая N-я проба».
- По умолчанию 5.
- Холостые пропускаются при счёте.
- Применяется при следующем импорте (автоматическая простановка флага — TODO).

### Кнопка «Сбросить к глобальным»
- Убирает переопределение, берёт значения из глобальных настроек.
