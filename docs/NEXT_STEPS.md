**Две задачи в одной серии.**

**C — перенос создания участков/нарядов в Редактирование.**

- Убрать из БД создание/удаление участков и нарядов.
- Добавить в Редактирование: «+ Участок» и «+ Наряд» — как с пробами.
- Для нового участка — указать префикс (записывается в настройки,
  используется при импорте нарядов).
- **`db-wells`** — просмотр скважин (сущность `OrderWellEntity`) —
  встроить как часть дерева Редактирования (Наряд → Скважины →
  Пробы), со сводкой «N проб / M отмечено».
- **Потребуются файлы:** `EditScreen.kt`, `EditViewModel.kt`,
  `SettingsRepository.kt`.

### Массовое создание проб

**Отдельная фича.** Идея зафиксирована:

- Создание участка с префиксом (пишется в настройки).
- Наряд → диалог создания проб:
  - скважина,
  - количество проб,
  - количество холостых (с указанием места),
  - авто-интервал по шагу,
  - тип проб.
- Предпросмотр с правкой (заполнение веса, характеристик).
- Копирование характеристик на несколько проб.
- Интеграция отдельных элементов в текущий Редактор.

Реализуется после B+C.
